# HM Finanças — Canal de atualizações

Esta pasta contém apenas o manifesto público usado pelo atualizador interno do HM Finanças.

O código-fonte continua no repositório privado `hibrael-mateus/hm-financas`.
Os APKs são publicados como assets de releases com tags no formato `hm-financas-vX.Y.Z`.
O aplicativo valida o SHA-256 do APK antes de abrir o instalador do Android.
